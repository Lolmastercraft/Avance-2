# Declaración de uso de inteligencia artificial en la entrega final

Se utilizó Codex como apoyo sustancial para inspeccionar el parche del profesor, adaptar la aplicación, escribir y ejecutar pruebas, configurar la instancia de Producción y preparar documentación y evidencias. También se utilizó para diagnosticar la falta de cobertura del pipeline original y corregir la autorización del reenvío.

El alumno seleccionó el buzón de prueba, proporcionó el acceso temporal al Learner Lab, entregó la captura de EC2 y expresó su reflexión personal sobre la dificultad para comprender partes de QA. Debe revisar la clasificación, comprender el cambio y validar la entrega antes de subirla a la plataforma. No se atribuye al alumno una ejecución manual de tareas realizadas por el asistente.

Los reportes provienen de ejecuciones reales en AWS y no se sustituyeron por salidas inventadas. Se documenta expresamente el pipeline original que pasó con la falla. Las credenciales no forman parte del repositorio, de las capturas ni del Word.
